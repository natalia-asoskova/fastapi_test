# Правила для ассистента

- Все суммы — `int` в копейках. Не использовать `float`, `round()`, `Decimal` для денег.
- Бизнес-логика (скидки, график рассрочки, переходы статусов) живёт в `app/price.py`
  и `app/statuses.py` как чистые функции без БД и HTTP. В роутерах её не дублировать.
- Допустимые переходы статусов менять только в `ALLOWED_TRANSITIONS`.
- Ответ 409 вебхука — `{"error": "invalid_transition"}` без обёртки `detail`.
- Любое изменение логики сопровождать тестом, который проверяет результат (суммы, статус
  в БД), а не только код ответа.
- Перед завершением работы: `ruff check . && pytest -q`.
